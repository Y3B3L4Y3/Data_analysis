# Data_analysis

This repository contains data analysis practice materials, source datasets, and solved notebook challenges.

## Project Structure

- `all_data_sources/`: raw and reusable datasets for analysis exercises.
- `solved_challenges/`: Jupyter notebooks with completed challenge solutions.

## Main Topics Covered

- Gender inequality indicators and country-level comparisons.
- Data model exploration and relationship behavior.
- Variable and calculated-column practice.
- Quick math and MCQ-style notebook exercises.
